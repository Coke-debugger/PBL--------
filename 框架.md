## 二、三层架构与依赖规则

```
core ←─ modules（按config注入，core不import modules）
  ↑         ↑
run.py   experiments（实验脚本直接import modules，不影响主流水线）
```

**注入方式（roundtable.py中的条件import）**：

```python
# core/roundtable.py
from configs import load_pipeline_config
config = load_pipeline_config("configs/pipeline.yaml")

if config["enable_argument"]:
    from modules.argument_graph import ArgumentGraphBuilder
    graph = ArgumentGraphBuilder().build(round0, round1, text)
else:
    # 降级为v2.0 LLM仲裁
    classified = self.conflict_classifier.classify(round0, round1)
```

**好处**：
- 验收批量运行：`enable_argument=false` 等于关掉所有 modules 的依赖链
- Shapley消融（创新1）：只改 `active_roles` config，不改代码
- 新增创新模块：只加 modules/，core不变

`judge_version` 运行时计算：
```python
# core/judge.py
def _compute_prompt_hash(self) -> str:
    manifest = json.loads(Path("prompts/manifest.json").read_text())
    hashes = [v["sha256"] for v in manifest["files"].values()]
    return hashlib.sha256("".join(hashes).encode()).hexdigest()[:12]
```

## 五、agents/registry.py（按名字启停，支持消融）

```python
# core/agents/registry.py
from .literacy_agent import LiteracyAgent
from .content_agent  import ContentAgent
from .learner_agent  import LearnerAgent
from .design_agent   import DesignAgent
from .chair_agent    import ChairAgent

AGENT_REGISTRY: dict[str, type] = {
    "r_literacy": LiteracyAgent,
    "r_content":  ContentAgent,
    "r_learner":  LearnerAgent,
    "r_design":   DesignAgent,
    "r_chair":    ChairAgent,
}

def build_agents(active_roles: list[str]) -> dict:
    """按PipelineConfig.active_roles实例化，消融实验按需组合"""
    return {rid: AGENT_REGISTRY[rid]()
            for rid in active_roles if rid in AGENT_REGISTRY}
```

```json
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "array",

    "required": ["issue_id","dimension","severity","location","quote",

    "properties": {
      "dimension":  {"enum": ["A","B","C","D","E","F"]},
      "severity":   {"enum": ["major","minor"]},

      "in_scope":   {"type": "boolean"},
      "rubric_anchor": {"type": ["string","null"]}
```


## 十、v1.0 → v2.0 变更清单

| 变更项 | v1.0 | v2.0 |
|--------|------|------|
| config管理 | 硬编码在run.py | `configs/` yaml文件 |
| types集中定义 | 散在各文件 | `core/types.py` |
| RunTrace追踪 | 无 | `core/trace.py` |
| 响应缓存 | 无 | `core/cache.py` |
| 创新模块隔离 | 与core混放 | `modules/`独立层 |
| 实验命名 | 方向1-4老命名 | 按新创新点命名 |
| Schema覆盖 | 仅process.json | 补annotation/review/verdict |
| prompts版本管理 | 无 | `manifest.json` |
| 角色注册表 | if-else硬编码 | `registry.py` |
| 单元测试 | 无 | `tests/` 覆盖4类纯函数 |
| 材料包管理 | 无固定位置 | `data/` 只读目录 |
| 实验产物 | 仅outputs_practice/ | `outputs/runs/{run_id}/` |
